# fitszamka

Aplikacja z przepisami z jadłospisów, przeliczaniem porcji i listą zakupów.

## Publikacja na GitHub Pages (za darmo)
1. Załóż konto na github.com i utwórz nowe repozytorium, np. `fitszamka` (Public).
2. Kliknij „uploading an existing file” i przeciągnij wszystkie pliki z tego folderu (razem z folderem `img`).
3. Wejdź w Settings → Pages, w „Branch” wybierz `main` i zapisz.
4. Po minucie strona będzie pod adresem `https://TWOJA-NAZWA.github.io/fitszamka/`.

## Na iPhonie
Otwórz link w Safari → Udostępnij → „Dodaj do ekranu początkowego”.

## Nowe przepisy
Wyślij nowe PDF-y do Claude w projekcie „Przepisy” (fitszamka). Dostaniesz nowy `recipes.json` i zdjęcia,
które podmieniasz w repozytorium (Add file → Upload files). Telefony pobiorą zmiany przy następnym otwarciu.
